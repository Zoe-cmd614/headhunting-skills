# 小麦 Agent Prompt：默认召回优先

小麦的第一轮任务是帮顾问把可能的人找出来，不是代替顾问和客户完成最终判断。默认 Prompt 要宽进、可解释、能自动扩展；详细画像留给人工二次筛选。

## 1. 默认原则

- 只把客户明确确认、缺失就一定无法任职的条件设为硬门槛；
- 学历、年限、同一公司类型、同一产品形态、头部平台、真机或精确技术词通常先写成“优先”，不要全部叠加；
- 信息缺失时标“待确认”，不能因为简历没写就直接排除；
- 直接池不足时按迁移逻辑自动扩展，不继续收紧条件；
- 输出字段保持少而有用，便于顾问快速点开简历；
- 来源公司和学校只用于扩展搜索，不自动决定人选等级。

## 2. 默认可复制模板

根据客户和岗位填写后，输出为一个连续、可整体复制的代码块；代码块内可以分行，但不要拆成多个表格或零散片段。不得残留空方括号。

```text
你是 TTC 的人才寻访 Agent。请为【客户名或保密代号】的【岗位名称】寻找候选人，Base【城市】，本轮先尽量召回可能相关的人，再由顾问二次筛选。

岗位主要要解决：【用两三句话写岗位真实使命，不复制 JD】。

重点搜索方向：
1. 【核心方向一】；
2. 【核心方向二】；
3. 【核心方向三】；
4. 【相邻但可能迁移的方向】。

优先关注：
- 【最有价值的项目、产品、研究或交付经历】；
- 【第二项优先证据】；
- 【第三项优先证据】。

以上优先项不是全部硬门槛。不要因为候选人缺少【容易过度卡人的条件，例如同一产品形态、头部公司、精确年限或学历】就直接排除；简历没有写清时标“待确认”。

明显降低优先级或排除：
- 【与岗位本质明显无关的方向】；
- 【确认后属于一票风险的情况】。

请先搜索直接相关的人选；如果数量不足，依次扩展到【相邻技术】、【相邻行业或产品】、【其他可迁移场景】和【高校/实验室/开源项目】。扩展人选必须说明迁移为什么可能成立，但不要因为证据不完整而不返回。

请尽量返回【20至30】位候选人。每人只需输出：
- 姓名；
- 当前公司或学校；
- 当前职位；
- 所在城市；
- 主要方向；
- 一句话推荐理由；
- 最需要人工确认的一项；
- 个人资料或人才库链接。

请按“直接相关、强迁移、高潜补充”分组，并在每组内按相关度排序。所有没有资料支持的学历、项目贡献、地点意愿、薪资和求职状态都写“待确认”，禁止猜测。
```

## 3. 具身或机器人岗位的宽搜示例

```text
请寻找机器人运动控制方向候选人，用于上海一家早期具身智能公司的机器人运控岗位。

重点方向包括：全身运动控制、Whole-Body Control；人形、双足、四足或移动操作机器人控制；力控、阻抗控制、柔顺控制；机器人动力学、MPC、QP、平衡控制；控制算法工程化、实时控制、ROS/ROS2与真机调试。

优先有真实机器人项目经验的人，但不要把“人形机器人经验”设成硬条件。机械臂、协作机器人、四足、外骨骼、康复机器人等方向也可以纳入，高校实验室中做过机器人控制的硕博也可以返回。不要因为简历没有写“全身运控”就直接排除，可以根据项目判断；信息不全时标待确认。

明显偏纯SLAM、导航、路径规划、纯视觉、纯PLC或电机驱动，且没有机器人控制算法经历的人，可以降低优先级。

请尽量返回30位候选人，每人输出姓名、当前公司/学校、职位、城市、主要方向、一句话推荐理由、需要人工确认的点和资料链接。如果直接匹配不足，请依次扩展到四足、机械臂力控、外骨骼、医疗/康复机器人以及高校机器人控制实验室，不要为了满足全部条件而最终不返回人选。
```

该示例只说明搜索宽度和语气，不把具身岗位条件套给其他职位。

## 4. 什么时候使用增强人才库模式

只有同时满足以下条件时，才增加复杂要求：

- 用户明确需要历史去重、活跃度、联系顺序或漏斗统计；
- 小麦或人才库确实有权限返回相关字段；
- 这些字段能影响本轮行动，而不是为了报告完整。

增强模式可按需增加：

- 与历史推荐、客户流程和明确拒绝记录去重；
- 标注近 30 天、31 至 90 天或未知活跃度；
- 对已返回人选选出今天优先联系的 Top 10；
- 对 Top 人选补充两条证据和个性化招呼语；
- 统计搜索、去重、排除和保留数量。

没有权限时必须说明能力边界，不能假装完成。不要把增强字段变成所有 Prompt 的默认负担。

## 5. 生成检查

- 硬门槛是否真的经过客户确认；
- 是否把详细画像整段复制成了搜索限制；
- 直接池不足时是否会自动扩展；
- 缺失信息是否会被保留为待确认；
- 是否存在条件叠加后可能零召回的问题；
- 输出字段是否便于顾问快速看人；
- 是否避免使用性别、年龄、婚育、民族等敏感条件；
- Prompt 是否连续可复制，没有空占位符。
- 客户未授权向外部工具披露时，是否使用了内部代号并删除非必要保密信息；生成 Prompt 本身不等于获得提交权限。
